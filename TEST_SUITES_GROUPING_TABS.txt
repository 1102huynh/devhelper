📑 TABS AVAILABLE
═══════════════════════════════════════════════════════════════════════════

1. All Tab
   - Shows: Tất cả test suites
   - Icon: None
   - Count: Total number
   - Example: "All (10)"

2. JUnit Tab (🟢)
   - Shows: JUnit test classes only
   - Filter: type === 'junit'
   - Count: JUnit tests count
   - Example: "🟢 JUnit (3)"
   - Auto-hide: Nếu không có JUnit tests

3. Cucumber Tab (🟣)
   - Shows: Cucumber feature files only
   - Filter: type === 'cucumber'
   - Count: Cucumber features count
   - Example: "🟣 Cucumber (2)"
   - Auto-hide: Nếu không có Cucumber features

4. XifinPortal Tab (🟠)
   - Shows: XifinPortal test suites only
   - Filter: type === 'xifinportal'
   - Count: Portal suites count
   - Example: "🟠 Portal (3)"
   - Auto-hide: Nếu không có Portal suites

5. Engine Tab (🔵 Cyan)
   - Shows: Engine test suites only
   - Filter: type === 'engine'
   - Count: Engine suites count
   - Example: "🔵 Engine (1)"
   - Auto-hide: Nếu không có Engine suites

6. REST API Tab (🔵 Blue)
   - Shows: REST API test suites only
   - Filter: type === 'restapi'
   - Count: API suites count
   - Example: "🔵 API (2)"
   - Auto-hide: Nếu không có API suites

💡 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

1. Tab Display Logic:
   - "All" tab luôn hiển thị
   - Các tab khác chỉ hiển thị nếu có test suite của loại đó
   - Dynamic grid: Tự động điều chỉnh số cột dựa trên số tabs

2. Tab Switching:
   - Click vào tab để filter test suites
   - State không bị mất khi switch tabs
   - Selected suites được giữ nguyên

3. Selection Behavior:
   - Chọn suite trong bất kỳ tab nào
   - Selection áp dụng cho tất cả tabs
   - "All" và "Clear" buttons hoạt động với tất cả tabs

4. Count Display:
   - Mỗi tab hiển thị số lượng test suites
   - Format: "Label (count)"
   - Update real-time khi data thay đổi

🔧 TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════

Component Structure:
──────────────────────────────────────────────────────────────────────────
<Tabs defaultValue="all">
  <TabsList grid-cols-6>
    <TabsTrigger "all" />
    {hasJUnit && <TabsTrigger "junit" />}
    {hasCucumber && <TabsTrigger "cucumber" />}
    {hasPortal && <TabsTrigger "xifinportal" />}
    {hasEngine && <TabsTrigger "engine" />}
    {hasAPI && <TabsTrigger "restapi" />}
  </TabsList>

  <TabsContent "all">
    {testSuites.map(...)}
  </TabsContent>

  <TabsContent "junit">
    {testSuites.filter(s => s.type === 'junit').map(...)}
  </TabsContent>

  ... other tabs
</Tabs>

Conditional Rendering Logic:
──────────────────────────────────────────────────────────────────────────
{testSuites.some(s => s.type === 'junit') && (
  <TabsTrigger value="junit">
    🟢 JUnit ({testSuites.filter(s => s.type === 'junit').length})
  </TabsTrigger>
)}

Filter Logic per Tab:
──────────────────────────────────────────────────────────────────────────
testSuites.filter(s => s.type === 'junit')  // JUnit tab
testSuites.filter(s => s.type === 'cucumber')  // Cucumber tab
testSuites.filter(s => s.type === 'xifinportal')  // Portal tab
testSuites.filter(s => s.type === 'engine')  // Engine tab
testSuites.filter(s => s.type === 'restapi')  // API tab
