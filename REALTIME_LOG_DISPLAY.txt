🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

1. Updated waitForTestCompletion() Function
   ────────────────────────────────────────────────────────────────────

   NEW LOGIC:
   ```typescript
   const waitForTestCompletion = (
       currentIndex: number,
       totalSuites: number,
       suiteName: string
   ): Promise<void> => {
       return new Promise((resolve) => {
           let lastLogLength = 0  // Track what we've already shown

           const poll = setInterval(async () => {
               // Get full log from backend
               const backendLog = await fetch(...).text()

               // Only append NEW lines
               if (backendLog.length > lastLogLength) {
                   const newLog = backendLog.substring(lastLogLength)
                   setTestLog(prev => prev + newLog)
                   lastLogLength = backendLog.length
               }

               if (!statusData.running) {
                   lastLogLength = 0  // Reset for next suite
                   resolve()
               }
           }, 1000)
       })
   }
   ```

   KEY IMPROVEMENTS:
   - Track `lastLogLength` để chỉ append log mới
   - Không ghi đè toàn bộ log
   - Không duplicate log
   - Reset counter cho suite tiếp theo

2. Enhanced Sequential Execution Display
   ────────────────────────────────────────────────────────────────────

   ```typescript
   // Show summary header
   setTestLog('=== Sequential Test Execution ===\n')
   setTestLog(prev => prev + `Total suites to run: ${totalCount}\n\n`)

   for each suite:
       // Show suite header
       setTestLog(prev => prev + `\n${'='.repeat(70)}\n`)
       setTestLog(prev => prev + `Suite ${i+1}/${total}: ${name}\n`)
       setTestLog(prev => prev + `Command: ${command}\n`)
       setTestLog(prev => prev + `${'='.repeat(70)}\n\n`)

       // Execute and stream logs
       await waitForTestCompletion(...)

       // Show completion
       setTestLog(prev => prev + `\n✓ Suite ${name} completed\n`)
   ```

   BENEFITS:
   - Clear visual structure
   - Shows command being executed
   - Progress indicator (Suite 1/3, 2/3, etc.)
   - Completion checkmark ✓

⚡ PERFORMANCE
═══════════════════════════════════════════════════════════════════════════

Polling Frequency:
  - Check every 1 second
  - Lightweight status check
  - Only fetch new log portion

Memory Efficient:
  - Track last position (lastLogLength)
  - Only process new bytes
  - No duplicate strings in memory

Network Efficient:
  - Full log fetch (unavoidable with current backend)
  - But only process delta client-side
  - Could optimize backend to support log offset
