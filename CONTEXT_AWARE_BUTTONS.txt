🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

1. New State Variable
   ────────────────────────────────────────────────────────────────────
   const [activeTestTab, setActiveTestTab] = useState<string>('all')

   Purpose: Track which tab is currently active
   Default: 'all'
   Values: 'all' | 'junit' | 'cucumber' | 'xifinportal' | 'engine' | 'restapi'

2. Updated selectAllSuites() Function
   ────────────────────────────────────────────────────────────────────
   const selectAllSuites = () => {
       let suitesToSelect: TestSuite[]

       if (activeTestTab === 'all') {
           suitesToSelect = testSuites
       } else {
           suitesToSelect = testSuites.filter(s => s.type === activeTestTab)
       }

       setSelectedSuites(new Set(suitesToSelect.map(s => s.className)))
   }

   Logic:
   - If tab = 'all' → Select all test suites
   - If tab = specific type → Select only that type

3. Updated clearAllSelections() Function
   ────────────────────────────────────────────────────────────────────
   const clearAllSelections = () => {
       if (activeTestTab === 'all') {
           setSelectedSuites(new Set())
       } else {
           const suitesToClear = testSuites
               .filter(s => s.type === activeTestTab)
               .map(s => s.className)
           const newSelected = new Set(selectedSuites)
           suitesToClear.forEach(className => newSelected.delete(className))
           setSelectedSuites(newSelected)
       }
   }

   Logic:
   - If tab = 'all' → Clear all selections
   - If tab = specific type → Clear only that type (keep others)

4. Tabs Component Integration
   ────────────────────────────────────────────────────────────────────
   <Tabs
       defaultValue="all"
       value={activeTestTab}
       onValueChange={setActiveTestTab}
   >

   Added:
   - value prop: Controlled component
   - onValueChange: Updates activeTestTab state

5. Button Labels Enhancement
   ────────────────────────────────────────────────────────────────────
   <Button onClick={selectAllSuites}>
       All {activeTestTab !== 'all' && `(${activeTestTab})`}
   </Button>

   <Button onClick={clearAllSelections}>
       Clear {activeTestTab !== 'all' && `(${activeTestTab})`}
   </Button>

   Display:
   - Tab "All" → "All" | "Clear"
   - Tab "JUnit" → "All (junit)" | "Clear (junit)"
   - Tab "Portal" → "All (xifinportal)" | "Clear (xifinportal)"
