🔧 IMPLEMENTATION

FRONTEND CHANGES:
────────────────────────────────────────────────────────────────────────

1. Enable openTerminal Flag
   ────────────────────────────────────────────────────────────────────
   ```typescript
   await fetch(`${API_BASE}/test/run`, {
       body: JSON.stringify({
           projectPath: selectedTestProject.path,
           command: command,
           openTerminal: true  // ← Enable real CMD window
       })
   })
   ```

2. No Polling Needed
   ────────────────────────────────────────────────────────────────────
   OLD:
   ```typescript
   await waitForTestCompletion()  // Wait and poll logs
   ```

   NEW:
   ```typescript
   // CMD window handles everything, just small delay
   await new Promise(resolve => setTimeout(resolve, 500))
   ```

3. Update UI Messages
   ────────────────────────────────────────────────────────────────────
   ```typescript
   setTestLog(prev => prev + `Opening CMD window for: ${suiteName}\n`)
   setTestLog(prev => prev + `Command: ${command}\n\n`)
   // ...
   setTestLog(prev => prev + `\n✅ Opened ${count} CMD windows\n`)
   setTestLog(prev => prev + `Check each CMD window for test results\n`)
   ```

BACKEND (Already Implemented):
────────────────────────────────────────────────────────────────────────

```java
if (openTerminal) {
    if (isWindows) {
        // Open new CMD window in project directory
        String cmdCommand = "start cmd.exe /K \"cd /d "
            + projectPath + " && " + command + "\"";
        ProcessBuilder pb = new ProcessBuilder("cmd.exe", "/c", cmdCommand);
        pb.start();

        // Return immediately
        return GitCommandResult.success("Test started in new CMD window", command);
    }
}
```

🎨 CMD WINDOW DETAILS
═══════════════════════════════════════════════════════════════════════════

Command Format:
  start cmd.exe /K "cd /d PROJECT_PATH && MAVEN_COMMAND"

Breakdown:
  - start: Opens new window
  - cmd.exe: Windows Command Prompt
  - /K: Keeps window open after command finishes
  - cd /d PROJECT_PATH: Navigate to project directory
  - &&: Chain commands
  - MAVEN_COMMAND: The actual test command

Example:
  start cmd.exe /K "cd /d D:\xifinportal-automation &&
    mvn clean test -DorgAlias=qa07 -DtestSuite=newXp\PatientSuite"
