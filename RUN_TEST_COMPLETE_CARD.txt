   cd backend && mvn spring-boot:run

2. Start frontend:
   cd frontend && npm run dev

3. Open: http://localhost:3000/jacoco-runner

4. Click tab "Run Test"

5. Select project from dropdown

6. Wait for test suites to load

7. Select test suites (click checkboxes)

8. Click "Start Execution"

9. Watch real-time logs
