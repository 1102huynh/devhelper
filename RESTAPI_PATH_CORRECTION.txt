🔧 CODE CHANGE
═══════════════════════════════════════════════════════════════════════════

Location: frontend/src/app/jacoco-runner/page.tsx

OLD CODE:
```typescript
if (suiteInfo?.type === 'restapi') {
    command = `mvn clean test -DOrgAlias=${orgAlias}
        -DUserId=${userId} -DUsername=${username}
        -DPassword=${password} -Denforcer.skip
        -DtestSuite=${suiteNameWithoutExt}`

```

NEW CODE:
```typescript
if (suiteInfo?.type === 'restapi') {
    // REST API tests - uses restassured\test\ path

        -DUserId=${userId} -DUsername=${username}
        -DPassword=${password} -Denforcer.skip
        -DtestSuite=restassured\\test\\${suiteNameWithoutExt}`
}
```

Key Change:

  - Note: Double backslash (\\) for JavaScript string escaping
