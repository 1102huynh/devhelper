🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

1. Updated Command Building Logic
   ────────────────────────────────────────────────────────────────────

   OLD CODE:
   ```typescript
   if (suiteInfo?.type === 'xifinportal' || suiteInfo?.type === 'engine') {
       command = `mvn clean test ... -DtestSuite=newXp\\${suiteName}`
   }
   ```

   NEW CODE:
   ```typescript
   if (suiteInfo?.type === 'xifinportal') {
       // XifinPortal tests - uses newXp path
       command = `mvn clean test -DforkCount=0 -Dmaven.surefire.debug
                  -DreuseForks=false -DorgAlias=${orgAlias}
                  -DtestSuite=newXp\\${suiteName}`
   } else if (suiteInfo?.type === 'engine') {
       // Engine tests - uses pfEngines path
       command = `mvn clean test -DforkCount=0 -Dmaven.surefire.debug
                  -DreuseForks=false -DorgAlias=${orgAlias}
                  -DtestSuite=pfEngines\\${suiteName}`
   }
   ```

2. Updated UI Helper Text
   ────────────────────────────────────────────────────────────────────

   OLD:
   "Portal/Engine Parameters: -DorgAlias=... -DtestSuite=newXp\[suite]"

   NEW:
   Shows separately based on selected suites:
   - "Portal: -DorgAlias=... -DtestSuite=newXp\[suite]"
   - "Engine: -DorgAlias=... -DtestSuite=pfEngines\[suite]"
