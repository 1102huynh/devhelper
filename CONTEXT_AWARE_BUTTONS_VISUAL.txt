💡 PRO TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Tip 1: Watch Button Labels
  → Labels change per tab
  → "All" vs "All (junit)" vs "All (xifinportal)"
  → Always know what you're selecting

Tip 2: Use All Tab for Overview
  → After mixed selection
  → Switch to All tab
  → See everything selected at once

Tip 3: Partial Clear is Safe
  → Clearing one type won't affect others
  → Example: Clear Portal, JUnit stays selected

Tip 4: Quick Reset Per Category
  → Instead of manually unchecking
  → Go to that tab → Click Clear

Tip 5: Build Up Selection
  → Start with one type (All button)
  → Switch tabs, add more (All button)
  → No need to hold Ctrl/Shift
