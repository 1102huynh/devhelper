✓ Tab counts show number of available tests
  Example: "🟢 JUnit (8)" = 8 JUnit tests available

✓ Tabs auto-hide if no tests of that type
  No JUnit tests? → No JUnit tab shown

✓ Selection preserved when switching tabs
  Select in JUnit tab → Switch to Portal → Selection kept

✓ "All" tab shows everything
  Use to see all selected items across types

✓ "All" button selects ALL tests (not just current tab)
  Global action affecting all test suites

✓ "Clear" button clears ALL selections
  Global action affecting all test suites

  Code: testSuites

  Code: testSuites.filter(s => s.type === 'junit')

  Filter: type === 'cucumber'
  Code: testSuites.filter(s => s.type === 'cucumber')

Portal Tab:
