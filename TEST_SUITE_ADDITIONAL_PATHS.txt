⚙️ TECHNICAL IMPLEMENTATION DETAILS
═══════════════════════════════════════════════════════════════════════════

scanTestSuiteDirectory() Method Logic:
────────────────────────────────────────────────────────────────────────

Input:
  - directory: Path to scan (newXp or pfEngines)
  - testSuites: List to append results to
  - type: 'xifinportal' or 'engine'

Process:
  1. Walk directory tree recursively
  2. Filter for regular files only
  3. Check file extension or name pattern
  4. Extract filename and relative path
  5. Remove extension for display name
  6. Create suite entry with metadata
  7. Add to testSuites list

Error Handling:
  - Catches and logs scanning errors
  - Continues if directory doesn't exist
  - Doesn't fail if files can't be read
