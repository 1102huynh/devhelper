FRONTEND (page.tsx)
────────────────────────────────────────────────────────────────────────

API Call:
  ```typescript

      method: 'POST',

          command: command                         // Maven command
      })
  })
  ```

No openTerminal flag → Use UI terminal

BACKEND (TestService.java)
────────────────────────────────────────────────────────────────────────

Key Code:
  ```java
  File dir = new File(projectPath);

  // Log working directory clearly
  log(projectId, "=".repeat(70));
  log(projectId, "Working Directory: " + projectPath);
  log(projectId, "Command: " + command);
  log(projectId, "=".repeat(70));

  // Set working directory for process
  ProcessBuilder processBuilder = new ProcessBuilder(cmdParts);
  processBuilder.directory(dir);  // CD to project directory
  processBuilder.redirectErrorStream(true);

  Process process = processBuilder.start();

  // Stream logs line by line
  try (BufferedReader reader = new BufferedReader(
          new InputStreamReader(process.getInputStream()))) {
      String line;
      while ((line = reader.readLine()) != null) {
          log(projectId, line);  // Real-time log
      }
  }
  ```

HOW IT WORKS:
  1. Frontend sends projectPath + command
  2. Backend receives and creates File(projectPath)
  3. ProcessBuilder.directory(dir) sets working directory
  4. Command executes IN that directory (like CD first)
  5. Logs stream back to frontend real-time
  6. Frontend displays in UI terminal

💡 WORKING DIRECTORY VERIFICATION
═══════════════════════════════════════════════════════════════════════════

How to verify CD is working:

1. Check Log Header
   ────────────────────────────────────────────────────────────────────
   Look for:
   ======================================================================
   Working Directory: D:\projects\xifinportal-automation
   ======================================================================

   This confirms backend set the directory

2. Maven Output
   ────────────────────────────────────────────────────────────────────
   Maven will show:
   [INFO] Building XifinPortal Automation 1.0.0
   [INFO]   from pom.xml

   If Maven finds pom.xml, directory is correct!

3. Test Execution
   ────────────────────────────────────────────────────────────────────
   Tests run successfully = correct directory
   If directory wrong, Maven would fail immediately with:
   [ERROR] The goal you specified requires a project to execute
           but there is no POM in this directory

4. File Paths in Logs
   ────────────────────────────────────────────────────────────────────
   Look for paths like:
   [INFO] Deleting D:\projects\...\target

   Should match your project path
