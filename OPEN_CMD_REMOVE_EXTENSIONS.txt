🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

FRONTEND (page.tsx)
────────────────────────────────────────────────────────────────────────

1. New Helper Function
   ────────────────────────────────────────────────────────────────────
   ```typescript
   const removeFileExtension = (fileName: string): string => {
       return fileName.replace(/\.(xml|properties|suite|json|feature)$/i, '')
   }
   ```

   Removes: .xml, .properties, .suite, .json, .feature (case-insensitive)

2. Updated Command Building
   ────────────────────────────────────────────────────────────────────
   ```typescript
   const suiteNameWithoutExt = removeFileExtension(suiteName)

   // Use suiteNameWithoutExt in commands
   if (type === 'restapi') {
       command = `... -DtestSuite=${suiteNameWithoutExt}`
   } else if (type === 'xifinportal') {
       command = `... -DtestSuite=newXp\\${suiteNameWithoutExt}`
   } else if (type === 'engine') {
       command = `... -DtestSuite=pfEngines\\${suiteNameWithoutExt}`
   }
   ```

3. Added openTerminal Flag
   ────────────────────────────────────────────────────────────────────
   ```typescript
   await fetch(`${API_BASE}/test/run`, {
       body: JSON.stringify({
           projectPath: selectedTestProject.path,
           command: command,
           openTerminal: true  // Open real CMD window
       })
   })
   ```

BACKEND (Java)
────────────────────────────────────────────────────────────────────────

1. GitCommandRequest.java
   ────────────────────────────────────────────────────────────────────
   Added field:
   ```java
   private boolean openTerminal;

   public boolean isOpenTerminal() { return openTerminal; }
   public void setOpenTerminal(boolean openTerminal) {
       this.openTerminal = openTerminal;
   }
   ```

2. TestController.java
   ────────────────────────────────────────────────────────────────────
   Updated to pass openTerminal flag:
   ```java
   @PostMapping("/run")
   public CompletableFuture<ResponseEntity<GitCommandResult>> runTest(
       @RequestBody GitCommandRequest request) {

       boolean openTerminal = request.isOpenTerminal();
       return testService.runTest(
           request.getProjectPath(),
           cmd,
           openTerminal
       ).thenApply(ResponseEntity::ok);
   }
   ```

3. TestService.java
   ────────────────────────────────────────────────────────────────────
   New signature:
   ```java
   public CompletableFuture<GitCommandResult> runTest(
       String projectPath,
       String command,
       boolean openTerminal)
   ```

   Logic:
   ```java
   if (openTerminal) {
       if (isWindows) {
           // Open new CMD window in project directory
           String cmdCommand = "start cmd.exe /K \"cd /d "
               + projectPath + " && " + command + "\"";
           ProcessBuilder pb = new ProcessBuilder(
               "cmd.exe", "/c", cmdCommand
           );
           pb.start();

           // Return immediately (don't wait)
           return GitCommandResult.success(
               "Test started in new CMD window", command
           );
       }
   }
   // Otherwise run in background (original behavior)
   ```

   Backward compatibility:
   ```java
   public CompletableFuture<GitCommandResult> runTest(
       String projectPath, String command) {
       return runTest(projectPath, command, false);
   }
   ```

🖥️ CMD WINDOW BEHAVIOR
═══════════════════════════════════════════════════════════════════════════

When openTerminal = true:

Windows Command:
  start cmd.exe /K "cd /d D:\project\path && mvn clean test ..."

Breakdown:
  - start: Open new window
  - cmd.exe: Command Prompt
  - /K: Keep window open after command completes
  - cd /d D:\project\path: Navigate to project directory
  - &&: Chain commands
  - mvn clean test ...: Execute Maven command

Result:
  ┌────────────────────────────────────────────────────────────┐
  │ Command Prompt - mvn clean test                            │
  ├────────────────────────────────────────────────────────────┤
  │ D:\project\path> mvn clean test -DorgAlias=qa07 ...       │
  │ [INFO] Scanning for projects...                           │
  │ [INFO] Building Project 1.0.0                             │
  │ [INFO] Running tests...                                   │
  │ ...                                                        │
  │                                                            │
  │ D:\project\path> _                                         │
  └────────────────────────────────────────────────────────────┘

Benefits:
  ✓ User sees real CMD window
  ✓ Can interact (Ctrl+C to stop)
  ✓ Window stays open after completion
  ✓ Can run additional commands
  ✓ Full control over terminal

✅ FILE EXTENSIONS REMOVED
═══════════════════════════════════════════════════════════════════════════

Regex Pattern: /\.(xml|properties|suite|json|feature)$/i

Matches:
  ✓ .xml        → PatientSuite.xml → PatientSuite
  ✓ .XML        → TEST.XML → TEST (case-insensitive)
  ✓ .properties → config.properties → config
  ✓ .suite      → regression.suite → regression
  ✓ .json       → api.json → api
  ✓ .feature    → login.feature → login

Does NOT Match:
  ✓ .java       → UserTest.java → UserTest.java (kept)
  ✓ .txt        → notes.txt → notes.txt (kept)
  ✓ no extension → TestSuite → TestSuite (unchanged)

⚠️ CONSIDERATIONS
═══════════════════════════════════════════════════════════════════════════

Real CMD Windows:
  ⚠️ Multiple windows can clutter screen
     → User can organize or minimize

  ⚠️ Must manually close windows
     → Windows stay open intentionally (/K flag)

  ⚠️ Windows-only feature
     → Linux/Mac would need different approach

File Extension Removal:
  ⚠️ Assumes Maven doesn't need extensions
     → Correct for most Maven setups

  ⚠️ Only removes known extensions
     → Other extensions kept as-is
