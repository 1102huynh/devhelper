🎯 WHAT IT DOES
───────────────────────────────────────────────────────────────
Select one or multiple test suites from a Maven project and
run them together with real-time log output.

🚀 QUICK START
───────────────────────────────────────────────────────────────
1. Go to "Run Test" tab
2. Select a project from dropdown
3. Check test suites you want to run
4. Click "Start Execution"
5. Watch real-time logs

📋 KEY FEATURES
───────────────────────────────────────────────────────────────
✓ Multi-select test suites
✓ Run single or multiple tests
✓ Real-time log streaming
✓ JUnit & Cucumber support
✓ "All" / "Clear" bulk actions
✓ Copy & clear log output

📝 USAGE EXAMPLES
───────────────────────────────────────────────────────────────

Example 1: Single Test
  Select: "UserServiceTest"
  Result: mvn test -Dtest=UserServiceTest

Example 2: Multiple Tests
  Select: "UserTest", "OrderTest", "PaymentTest"
  Result: mvn test -Dtest=UserTest,OrderTest,PaymentTest

Example 3: All Tests
  Click: "All" button
  Result: mvn test -Dtest=[all test classes]

Example 4: Custom Command
  Clear all selections
  Type: "mvn clean test -X"
  Result: mvn clean test -X
