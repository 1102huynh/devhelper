TEST RUNNER - RUN TEST TAB IMPLEMENTATION
==========================================
Date: December 17, 2025

OVERVIEW
--------
Enhanced the jacoco-runner tool with a complete test suite selection and execution feature.
Users can now select one or multiple test suites from a project and run them together.

BACKEND CHANGES
---------------

1. TestController.java
   - Added new endpoint: GET /api/test/suites?projectPath={path}
   - Returns list of available test suites (JUnit and Cucumber)

2. TestService.java
   - Added getTestSuites() method
   - Scans Maven project structure (src/test/java)
   - Detects JUnit test files (*Test.java, *Tests.java, *IT.java)
   - Detects Cucumber feature files (*.feature)
   - Returns test suite metadata: name, className, path, type

FRONTEND CHANGES
----------------

1. New Interface
   - TestSuite interface with name, className, path, and type fields

2. New State Variables
   - testSuites: List of available test suites
   - selectedSuites: Set of selected test suite class names
   - loadingSuites: Loading state for test suites

3. New Functions
   - loadTestSuites(): Fetches test suites from backend when project is selected
   - toggleSuiteSelection(): Toggle individual suite selection
   - selectAllSuites(): Select all available test suites
   - clearAllSelections(): Clear all selections
   - Updated runTest(): Builds Maven command with selected test suites

4. UI Enhancements
   - Test suites list with checkboxes
   - Visual indication of selected suites
   - Badge showing selection count (e.g., "3/10")
   - "All" and "Clear" buttons for bulk selection
   - JUnit and Cucumber badges for each suite
   - Scrollable test suite list (max-height: 300px)
   - Auto-load test suites when project is selected
   - Shows helpful message when no suites are available

FEATURES
--------

✓ Select project from dropdown
✓ Automatically load available test suites
✓ Display test suites with type badges (JUnit/Cucumber)
✓ Click to select/deselect individual test suites
✓ Select all suites at once
✓ Clear all selections at once
✓ Shows selection count badge
✓ Run selected test suites (builds mvn test -Dtest=Suite1,Suite2,Suite3)
✓ Run all tests if no suite selected (uses custom command)
✓ Real-time log output with live updates
✓ Terminal-style output display
✓ Copy log to clipboard
✓ Clear log output
✓ Visual feedback during test execution

USAGE FLOW
----------

1. User selects a project from the dropdown
2. System automatically scans and loads available test suites
3. User can:
   - Select one or more test suites by clicking on them
   - Use "All" button to select all suites
   - Use "Clear" button to deselect all
4. User clicks "Start Execution"
5. System builds appropriate Maven command:
   - If suites selected: mvn test -Dtest=Suite1,Suite2,Suite3
   - If no suites: Uses custom command field
6. Real-time log output appears in terminal-style display
7. Test status updates live until completion

TECHNICAL NOTES
---------------

- Backend scans both Maven (src/test/java) and Cucumber (features) directories
- Supports JUnit test files and Cucumber feature files
- Command building uses Maven's -Dtest parameter for selective execution
- Polling mechanism updates log every 1 second during execution
- Test suites are stored by className for unique identification
- UI uses Set data structure for efficient selection management
