📋 UPDATE SUMMARY
═══════════════════════════════════════════════════════════════════════════

Đã cập nhật để support 3 loại test suites với parameters khác nhau:

1. Portal/Engine Tests:
   mvn clean test -DforkCount=0 -Dmaven.surefire.debug
   -DreuseForks=false -DorgAlias=${orgAlias} -DtestSuite=newXp\${suite}

2. REST API Tests:
   mvn clean test -DOrgAlias=${orgAlias} -DUserId=${userId}
   -DUsername=${username} -DPassword=${password}
   -Denforcer.skip -DtestSuite=${suite}

3. JUnit/Cucumber Tests:
   mvn test -Dtest=${testName}

🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

1. New State Variables
   ────────────────────────────────────────────────────────────────────
   const [orgAlias, setOrgAlias] = useState('qa07')     // Dropdown
   const [userId, setUserId] = useState('chava')         // Dropdown
   const [username] = useState('webservicetest')         // Fixed
   const [password] = useState('webservicetest')         // Fixed

2. Parameter Options
   ────────────────────────────────────────────────────────────────────
   OrgAlias:
     - qa07 (default)
     - qa08
     - Applies to: Portal, Engine, REST API

   UserId (REST API only):
     - chava (default)
     - qatester

   Username (REST API only):
     - webservicetest (fixed)

   Password (REST API only):
     - webservicetest (fixed)

3. Updated runTest() Logic
   ────────────────────────────────────────────────────────────────────
   Command Building per Type:

   IF type === 'restapi':
     → mvn clean test
       -DOrgAlias=${orgAlias}
       -DUserId=${userId}
       -DUsername=${username}
       -DPassword=${password}
       -Denforcer.skip
       -DtestSuite=${suiteName}

   ELSE IF type === 'xifinportal' | 'engine':
     → mvn clean test
       -DforkCount=0
       -Dmaven.surefire.debug
       -DreuseForks=false
       -DorgAlias=${orgAlias}
       -DtestSuite=newXp\${suiteName}

   ELSE (JUnit/Cucumber):
     → mvn test -Dtest=${suiteName}

4. UI Changes
   ────────────────────────────────────────────────────────────────────
   New Section: "Test Parameters"

   Always shown (when suites selected):
     ✓ OrgAlias dropdown (qa07, qa08)

   Conditionally shown (when REST API suite selected):
     ✓ UserId dropdown (chava, qatester)
     ✓ Username field (disabled, fixed value)
     ✓ Password field (disabled, fixed value)
     ✓ Parameter preview text

   Helper Text:
     - REST API: Shows all 4 parameters
     - Portal/Engine: Shows orgAlias and testSuite format

🔄 EXECUTION FLOW
═══════════════════════════════════════════════════════════════════════════

Sequential Execution with Different Commands:

For each selected suite:

  1. Identify suite type

  2. Build appropriate command:

     REST API:
       mvn clean test -DOrgAlias=${orgAlias} -DUserId=${userId}
       -DUsername=${username} -DPassword=${password}
       -Denforcer.skip -DtestSuite=${suite}

     Portal/Engine:
       mvn clean test -DforkCount=0 -Dmaven.surefire.debug
       -DreuseForks=false -DorgAlias=${orgAlias}
       -DtestSuite=newXp\${suite}

     JUnit/Cucumber:
       mvn test -Dtest=${suite}

  3. Execute command

  4. Wait for completion

  5. Move to next suite
