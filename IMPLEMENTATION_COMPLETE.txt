📊 FUNCTIONAL FLOW
═══════════════════════════════════════════════════════════════════════════

STEP 1: Select Project
  User clicks dropdown → Shows project list
  User selects project → Triggers loadTestSuites()

STEP 2: Load Test Suites
  Frontend: GET /api/test/suites?projectPath=...
  Backend: Scans test directories
  Returns: Array of test suite objects
  Frontend: Displays list with checkboxes

STEP 3: Select Suites (Optional)
  User clicks suite → Toggles selection (Set add/remove)
  OR clicks "All" → Selects all suites
  OR clicks "Clear" → Deselects all suites
  Counter updates: X/Y badge

STEP 4: Run Tests
  IF suites selected:
    Command = mvn test -Dtest=Suite1,Suite2,Suite3
  ELSE:
    Command = custom command from input field

  Frontend: POST /api/test/run { projectPath, command }
  Backend: Executes command asynchronously
  Frontend: Polls every 1s for log & status

STEP 5: Display Results
  Terminal shows real-time logs
  Status updates (running/finished)
  Notification on completion

5. Select Project from Dropdown
