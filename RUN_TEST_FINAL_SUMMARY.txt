🔧 TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════

Backend Implementation (TestService.java)
────────────────────────────────────────────────────────────────────────

Method: getTestSuites(String projectPath)
  1. Scan src/test/java → JUnit tests
  2. Scan src/test/resources/features → Cucumber
  3. Scan src/test/resources/newXp → XifinPortal
  4. Scan src/test/resources/pfEngines → Engines
  5. Scan src/test/resources/restassured → REST API
  6. Return combined list

Helper Method: scanTestSuiteDirectory(Path, List, String)
  - Input: directory path, result list, type name
  - Filters: .xml, .properties, .suite, .json
  - Also: files containing "suite" or "test"
  - Output: Map with name, className, path, type

Frontend Implementation (page.tsx)
────────────────────────────────────────────────────────────────────────

Interface:
  type TestSuite = {
    name: string
    className: string
    path: string
    type: 'junit' | 'cucumber' | 'xifinportal' | 'engine' | 'restapi'
  }

Badge Color Logic:
  junit → Green
  cucumber → Purple
  xifinportal → Orange
  engine → Cyan
  restapi → Blue (default/fallback)

🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

Bước 1: Start Backend
  cd D:\practices\devhelper\backend
  mvn spring-boot:run

Bước 2: Start Frontend
  cd D:\practices\devhelper\frontend
  npm run dev

Bước 3: Mở Browser
  http://localhost:3000/jacoco-runner

Bước 4: Chọn Tab "Run Test"

Bước 5: Chọn Project
  - Dropdown hiển thị danh sách projects
  - Click chọn project muốn test

Bước 6: Xem Test Suites
  - Tự động load sau khi chọn project
  - Hiển thị tất cả test suites với badges màu

Bước 7: Chọn Test Suites
  - Click vào suite để chọn/bỏ chọn
  - Hoặc click "All" để chọn tất cả
  - Hoặc click "Clear" để bỏ chọn tất cả

Bước 8: Run Tests
  - Click "Start Execution"
  - Xem real-time logs trong terminal
  - Đợi notification khi hoàn thành
