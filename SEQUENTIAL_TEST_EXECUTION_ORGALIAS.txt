📋 FEATURE SUMMARY

Đã implement tính năng chạy test suites theo format Maven mới:

Command Format:
  mvn clean test -DforkCount=0 -Dmaven.surefire.debug
  -DreuseForks=false -DorgAlias=${orgAlias} -DtestSuite=newXp\${suite}

Key Changes:
  ✅ Thêm OrgAlias input field (required khi chọn suites)
  ✅ Sequential execution: Chạy từng suite một theo thứ tự
  ✅ Smart command building theo type của test suite
  ✅ Real-time log cho từng suite
  ✅ Progress indicator (Suite 1/5, Suite 2/5,...)

🔧 TECHNICAL CHANGES
═══════════════════════════════════════════════════════════════════════════

1. New State Variable
   ────────────────────────────────────────────────────────────────────
   const [orgAlias, setOrgAlias] = useState('')

   Purpose: Store user input for OrgAlias parameter
   Required: Yes (when running test suites)

2. Updated runTest() Function
   ────────────────────────────────────────────────────────────────────
   Logic Flow:

   A. Validation:
      - Check if project selected
      - Check if orgAlias provided (when suites selected)

   B. Execution Strategy:

      IF no suites selected:
         → Use custom command from input field
         → Run once

      ELSE (suites selected):
         → Run each suite sequentially
         → For each suite:
            1. Build specific command
            2. Trigger API
            3. Wait for completion
            4. Move to next suite

   C. Command Building:

      IF type === 'xifinportal' | 'engine' | 'restapi':
         → Maven command with full parameters:
           mvn clean test -DforkCount=0 -Dmaven.surefire.debug
           -DreuseForks=false -DorgAlias=${orgAlias}
           -DtestSuite=newXp\${suiteName}

      ELSE (JUnit/Cucumber):
         → Simple Maven command:
           mvn test -Dtest=${suiteName}

3. New Helper Functions
   ────────────────────────────────────────────────────────────────────

   startPolling():
     Purpose: Poll for test status/logs continuously
     Used: When running custom command (no suites selected)

   waitForTestCompletion():
     Purpose: Wait for single suite to complete
     Returns: Promise<void>
     Used: In sequential execution loop

4. UI Addition
   ────────────────────────────────────────────────────────────────────

   OrgAlias Input Field:
     - Only shown when: Project selected AND suites selected
     - Visual: Orange highlighted box
     - Required: Yes (shows * indicator)
     - Validation: Must not be empty
     - Placeholder: "Enter OrgAlias (e.g., xifin, demo, client)"

⚙️ CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

Maven Parameters (for Portal/Engine/API suites):
  -DforkCount=0         → No parallel forks
  -Dmaven.surefire.debug → Enable debug mode
  -DreuseForks=false    → Don't reuse forks
  -DorgAlias=...        → Organization alias
  -DtestSuite=newXp\... → Test suite path

Command Template:
  mvn clean test -DforkCount=0 -Dmaven.surefire.debug
  -DreuseForks=false -DorgAlias=${orgAlias} -DtestSuite=newXp\${suite}
